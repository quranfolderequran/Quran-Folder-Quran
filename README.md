# Islamic Session — Classical Online Quran Academy

> **Reviving the Classical Elegance of Sacred Recitation**  
> An international online Quran academy platform designed with an authentic **"Al-Andalus Alhambra"** aesthetic, built with **Next.js 16 (App Router)** and **Tailwind CSS**.

---

## 🌟 Key Features

- **🏛️ Bespoke Al-Andalus Theme**: Curated Moorish luxury palette featuring Twilight Obsidian (`#0B070A`), Terracotta Silk (`#C25E3E`), and Lantern Amber/Copper-Gold (`#E6A656` / `#D89547`) with Google Fonts (*Playfair Display, Outfit, Amiri, Scheherazade New*).
- **📖 20 Comprehensive Pages**:
  - **Home (`/`)**: 3D Alhambra Hero, founder spotlight, soundboard lab, course cards, calculator, and diaspora testimonials.
  - **About Us (`/about`)**: Sanad transmission chains, heritage, female scholars, and virtual classroom methodology.
  - **Courses Hub (`/courses`)**: 5 category filters and 4-stage learning roadmap.
  - **8 Course Detail Pages (`/courses/[slug]`)**: Dedicated curriculum modules, learning outcomes, target audiences, and trial CTAs for every course.
  - **Fee Structure (`/fee`)**: Multi-currency pricing (USD & GBP), automated 30% family sibling discount calculator, and 100% satisfaction guarantee.
  - **FAQ (`/faq`)**: Searchable, categorized accordions with Schema.org `FAQPage` markup.
  - **Contact Us (`/contact`)**: Direct WhatsApp & Email channels, timezone indicator, and secured contact form.
- **🔊 Interactive Makharij Soundboard**: Real-time Web Audio API articulation synthesizer for authentic Arabic phonetic mastery.
- **💰 Dynamic Tuition Calculator**: Real-time pricing calculator supporting 2 to 5 lessons/week in USD and GBP with automated sibling savings.
- **🗓️ 3-Day Free Trial Booking Modal**: Universal modal with live platform selector (**Zoom, Microsoft Teams, WhatsApp**), honeypot anti-spam defense, and instant pre-filled WhatsApp confirmation.
- **💬 WhatsApp Concierge Integration**: Floating concierge button with pulsing aura, live typing indicator, and instant direct WhatsApp inquiry links.
- **💳 Accepted International Payment Gateways**: Payoneer, Western Union, Bank Transfer, and Remitly.
- **⭐ 10 Verified Global Diaspora Reviews**: Heartfelt feedback from families across the UK, USA, Canada, Australia, and the UAE with category filter tabs.
- **🚀 Advanced SEO & Security**: Next.js metadata, automated `sitemap.xml`, `robots.txt`, JSON-LD schemas (`EducationalOrganization`, `Course`, `FAQPage`), and API rate-limiting.

## 💻 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) + Custom CSS Design System
- **Icons**: [Lucide React](https://lucide.dev/) & Custom SVG Vectors
- **Audio Synthesis**: Native Web Audio API
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

### 1. Prerequisites
Ensure you have **Node.js 18+** installed on your system.

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for Production
```bash
npm run build
npm run start
```
